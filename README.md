# iPhone 18 Pro Camera Field Guide

iPhone 14 から iPhone 18 Pro に乗り換えた人向けの、旅行・街歩き・絶景・夜景・料理・人物・動画撮影の実戦ガイドです。

## まず覚えること

- 普段の写真：**24MP**
- 普段の動画：**4K / 30fps**
- 迷ったら：**1× / Auto**
- 明るい絶景・建築：必要な時だけ **HEIF 48MP**
- 夜景：まず **1×**。手ぶれを抑え、白飛びする時だけ露出を下げる
- 人物・料理：**2× / 4×** や **35mm** を積極的に使う
- ProRAW / ProRes：編集前提の時だけ使う

詳しい場面別レシピは [index.html](./index.html) にまとめています。

## このガイドの考え方

iPhone 18 Pro は機能が多いですが、毎回すべてを手動操作する必要はありません。

**場面 → レンズ → 画質 → 必要なら1項目だけ手動調整**

の順に考えると、旅行中でも迷いにくくなります。
