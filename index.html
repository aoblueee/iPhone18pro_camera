レンズは「距離感」で選ぶ

ピンチズームを細かく動かすより、まずは 0.5 / 1 / 2 / 4 / 8 の定位置から選ぶと失敗しにくい。

0.5× · 13mm

超広角

絶景、巨大建築、狭い室内。「広さ」を見せたい時。

人物を画面端に置くと歪みやすい。

1× · 24 / 28 / 35mm

メイン

画質優先の主役。24mm=広め、28mm=自然、35mm=写真らしい切り取り。

迷ったらここ。

2× · 48mm

標準寄り望遠

料理、人物、街のディテール。余計な背景を減らしやすい。

4× · 100mm

48MP望遠

人物、建物の一部、山、圧縮感のある写真。iPhone 14ではできなかった「遠くをきれいに切り取る」領域。

8× · 200mm

光学品質の超望遠

遠景、塔、山の稜線、ステージ。明るい屋外ほど強い。暗所では1×や4×を優先。

24 / 28 / 35mm：1×ボタンをタップして切り替え。街歩きは28mm、カフェやスナップは35mmを試すと「スマホっぽい広角感」が減る。

場面から選ぶ。旅行用レシピ

City / Architecture

🏙 街並み・建築

レンズ1× 24mm / 28mm。大きな建物は0.5×画質24MP。明るく静止した景色はHEIF 48MP手動基本Auto。必要なら露出 -0.3程度コツグリッド＋水平。垂直線が倒れすぎない位置から撮る
Landscape

🌄 絶景・自然

レンズ1×を基準。広がりは0.5×、山の層は4×画質24MP / 明るい時は48MP手動空が白飛びする時だけ露出を少し下げるコツ「全部入れる」より前景を1つ置くと奥行きが出る
Food / Cafe

🍜 料理・カフェ

レンズ35mm または2×。真上撮りは1×画質24MP手動基本Auto。明るすぎるテーブルは露出を少し下げるコツ0.5×で料理に近づきすぎない。2×で少し離れると自然
Portrait

🧑 人物・友達

レンズ2× or 4×。全身＋景色なら1×/35mm画質24MPモードまず「写真」で撮る。深度情報があれば後からポートレート化コツ顔を0.5×の端に置かない。背景との距離を取る
Night

🌃 夜景・夜市

レンズ1×最優先。明るい被写体なら2×/4×画質24MP / ナイトモードAuto手動触らなくてOK。メインで絞りを触るならƒ/1.48が暗所向きコツ両手で固定。壁・手すりに寄せる。街灯の白飛びは露出を下げる
Sunset

🌅 夕焼け・逆光

レンズ1× / 太陽を大きく見せるなら4×画質24MP、十分明るければ48MP手動太陽付近をタップ → ☀︎を下へ。目安 -0.3〜-0.7コツ暗部を少し犠牲にして空の色を残す
Motion

🐎 動物・乗り物・歩く人

レンズ1×〜4×。被写体との距離で選ぶ画質24MPAF被写体をタップ → 黄色枠をダブルタップで追尾手動ブレる時だけシャッター 1/250秒以上を目安
Macro

🌿 花・小物・料理の超接写

レンズ近づくとマクロへ自動切替画質通常24MP。十分明るく細部を残したい時は48MPを検討操作🌷マークでマクロ切替を制御コツ近すぎて影を作らない。少し離れて光を入れる

手動操作は「困った時だけ」使う

18 Proは絞り、シャッタースピード、ホワイトバランス、マニュアルフォーカス、ヒストグラムを標準カメラで扱える。でも、Autoが失敗している理由が分かる時だけ触るのがいちばん簡単。

露出 ☀︎

最優先で覚える。被写体をタップし、横の太陽マークを上下。

  • 空・ネオンが白い → 下げる
  • 顔が暗い → 少し上げる
  • 長押しでAE/AFロック

絞り · Mainのみ可変

ƒ/1.48 / 1.8 / 2.8 / 4.0。数字が小さいほど明るく、背景がぼけやすい。

  • 夜・主役1人 → ƒ/1.48〜1.8
  • 料理・街 → ƒ/2.8
  • 風景・複数人 → ƒ/4.0

シャッタースピード

被写体がブレる時に使う。

  • 歩く人：1/125秒〜
  • 動物・子ども：1/250秒〜
  • 速い乗り物：1/500秒〜

速くするほど光が不足しやすい。暗所ではAuto推奨。

ホワイトバランス

写真は基本Auto。動画で照明が変わるたび色がフラフラする時に固定すると有効。

昼光の目安は5600K。数値を上げると暖かく、下げると冷たく見える。

マニュアルフォーカス

ガラス越し、暗所、小物など、AFが迷う時だけ。18 Proはピント面を輪郭表示できる。

ヒストグラム

右端に山がべったり張り付く → 白飛びの可能性。夕焼けや雪景色など、明暗差が大きい時に確認。

カメラコントロール、どう使えばいい？

クリック カメラを開く / 撮影。
軽くダブルプレス コントロールを表示。
スライド ズームや露出などの値を変更。

最初はズームと露出だけ使えれば十分。設定項目を増やしすぎない方が速い。

動画は4K30を基準にする

シーンおすすめ使い分け
普通の旅行Vlog4K / 30fps基本はこれ。暗所にも比較的強く、容量も現実的。
歩く人・乗り物4K / 60fps動きを滑らかに。明るい日中向き。
走る・激しい歩き撮りアクションモード手ぶれを強く抑えたい時。
人物を映画っぽくシネマティック 4K / 30fps背景ぼけとフォーカス移動を活かす。
本気編集ProRes / Log 2色編集を前提にした作品用。普段はOFF。

60fpsは万能ではない。暗い場所では30fpsの方が光を取り込みやすい。夜市・室内・夕方はまず4K30。

海外旅行での撮り方の型

Step 1

まず24MP・1×

到着したら何も考えず記録。シャッターチャンスを逃さない。

Step 2

同じ場所でもう1枚

0.5×で広さ、4×でディテール。写真のバリエーションを作る。

Step 3

特別な1枚だけ48MP

昼の絶景・建築など、細部を残したい静止シーンに限定。

旅先での5秒チェック

  1. レンズ汚れてない？ 夜景は特に指紋が大敵。
  2. 倍率は適切？ 迷ったら1×。人物は2×/4×。
  3. 水平？ 海・建物は水準器を見る。
  4. 明るすぎない？ 白飛びしていたら露出を少し下げる。
  5. もう1カット撮った？ 広角 / 寄り / 縦動画のどれかを追加。

やりがちな失敗

全部48MPにする

容量・処理・撮影テンポが重くなる。普段24MP、特別な静止画48MPで十分。

暗いのに8×を使う

望遠は光が必要。夜は1×で撮って後から切り取る方が良い場合が多い。

0.5×で人物を端に置く

顔や体が伸びやすい。超広角は景色のために使い、人物は中心寄りへ。

ProRes / RAWを常時ON

「Pro」という名前に釣られない。編集の自由度が必要な時だけ使う。
